# Тихая Гавань

Статический сайт турбазы на полуострове Копылово: 71 страница и 43 позиции каталога. Адаптивный интерфейс, реальные фотографии, выбор и сравнение проживания, галереи, видео и заявки в WhatsApp.

## Запуск

Требуется Node.js 20+. Установка зависимостей не нужна.

```sh
node tools/build.mjs
node tools/serve.mjs
```

Предпросмотр: http://127.0.0.1:4175/.

Готовые файлы для размещения — `docs/`. Инструкция по редактированию, передаче и публикации: [DELIVERY.md](DELIVERY.md).

Источники: [SOURCES.md](SOURCES.md). Принципы оформления: [DESIGN.md](DESIGN.md). Фотографии и обработка: [evidence/media.json](evidence/media.json).

Заявки открывают подготовленное сообщение в WhatsApp или почтовой программе посетителя. Наличие мест и окончательную стоимость подтверждает администратор.
